# Repository Availability Notice

## Note for Visitors from LinkedIn

If you arrived here through one of my previous LinkedIn posts about the **MNIST CNN Accelerator** or **Camera-to-VGA Video Streaming System on FPGA**, please note that the original public GitHub repositories linked in those posts have been deleted.

I initially intended to make the repositories private while evaluating potential directions for future academic research and master's degree studies. However, after realizing that the repositories had already been forked, I became concerned about the continued public availability of the source code and made a hasty decision to delete the original repositories.

I acknowledge that deleting them was a rushed decision, and I apologize for any confusion or inconvenience caused by the broken links in my previous LinkedIn posts.

## Current Project Status

Both projects have been preserved and recreated in new private repositories.

**Neither project has been abandoned or discontinued.** The source code, hardware verification results, implementation reports, and technical documentation remain part of my ongoing development and research preparation.

For the time being, I have decided to keep the repositories private until my future academic research direction becomes clearer.
